# Smart Home Device Manager

## Unit I Mini Project

### Project Description

The Smart Home Device Manager is a C++ console-based application that manages smart devices in a home.

The system stores information about each smart device such as:

- Device ID
- Device name
- Location
- Current status
- Last updated time

The application allows the user to control devices and view the overall home dashboard.

## Features

1. Add smart devices to the system.
2. Switch devices ON.
3. Switch devices OFF.
4. Change the device status.
5. Update the last updated time.
6. Display the complete home dashboard.

## Smart Devices Used

The project demonstrates the management of:

- Light
- Thermostat
- Camera
- Door Lock

## OOP Concepts Used

This project demonstrates the following Object-Oriented Programming concepts:

- Class and Object
- Encapsulation
- Private Data Members
- Constructors
- Member Functions
- Vector of Objects
- Range-Based For Loop
- Data Abstraction
